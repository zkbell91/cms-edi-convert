Edit the PDF.
Review the claim.
Save an EDI file.

This converter reads fillable CMS-1500 form fields and writes a local 837P file. It remembers practice and payer settings. It does not upload claims.

  1. Install with python3 install_cli.py, or double-click Run Converter.command (Mac) / Run Converter.bat (Windows).
  2. Click Try synthetic demo to test with fictional data.
  3. Open Practice & payer settings. Add rendering-provider names. Common commercial payers resolve automatically; override a payer ID only when needed.
  4. Edit and save your PDF using its form fields. For corrections, put 7 in Box 22 with the payer’s original claim number.
  5. Choose the PDF, compare the review to the form, then Save EDI file. Test mode is the default.
  6. Upload the .edi through your clearinghouse or payer channel and review their acknowledgments.
Scope: One fillable form at a time, primary commercial outpatient claims, up to six service lines. Scans, flattened PDFs, secondary claims, and Medicare workflows are not supported.

Terminal

cms-edi-convert input.pdf output.edi

See CLI_GUIDE.md for review, fields, refresh, and settings commands.

When an edit does not display correctly

If stored values disagree with the on-screen appearance, conversion stops. Refresh PDF fields creates a separate copy from stored values. Inspect that copy before converting.

Check these

  • Confirm expanded birth dates in the review (two-digit years on the form are expanded).
  • Box 22’s payer claim number is not your Box 26 account number.
  • Box 29 is actual patient money already paid.

Requires Python 3.10+ with Tkinter. PDF libraries are bundled.
