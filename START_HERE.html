Edit the PDF.
Review the claim.
Save an EDI file.

This reusable converter reads the actual fields in the supplied TheraNest CMS-1500 template. It remembers your practice and payer settings. It does not upload claims or change TheraNest.

  1. Extract the whole ZIP. Double-click Run Converter.command on Mac, or Run Converter.bat on Windows.
  2. Click Try synthetic demo to test the workflow with fictional data.
  3. Open Practice & payer settings. Enter the payer's verified Stedi ID; the Florida entry is intentionally blank. Keep leading zeros.
  4. Edit and save your PDF using its form fields. For corrections, fill Box 22 with 7 and the original payer claim number, change the CPT, and update charges if needed.
  5. Choose the PDF, compare the extracted review with the saved form, then select Save EDI file. Test mode is the default.
  6. Upload the resulting .edi in Stedi under Claims → Submit claim → Upload raw X12 file. Review Stedi's validation and acknowledgments.
Scope: One fillable form at a time, primary commercial outpatient claims, up to six service lines. This version stops on unsupported populated fields. Scans, flattened PDFs, secondary claims, and Medicare workflows are not supported.

Terminal works too

cms-edi-convert input.pdf output.edi

The CLI shares the desktop settings and can edit every PDF field and configuration setting. CLI instructions and examples.

When an edit does not display correctly

The program checks stored field values against saved appearances. If they disagree, it stops. Refresh PDF fields creates a separate copy using the stored values. Open that copy and inspect it before conversion; your original stays unchanged. Use actual form fields, not white rectangles or added text boxes.

Three details to check

  • Enter four-digit birth years. Two-digit service years are treated as 20xx.
  • The original payer claim number in Box 22 is different from your internal account number in Box 26.
  • Box 29 is actual patient money already paid, not estimated copay or insurer payment.

What gets saved

A folder with the EDI file, readable review, and a record connecting the source account number to the new outgoing claim identifier. Keep these alongside your claim records.

No live Stedi acceptance test has been performed. The included synthetic example generates test files only. Production files are clearly marked and can be sent to payers if you later submit them.

Requires Python 3.10+ and Tkinter; the launcher can use this Mac's installed Codex runtime. PDF dependencies are bundled. Windows launcher supplied but not tested on Windows.
